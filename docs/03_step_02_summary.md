# 第 2 步总结：Python 基础与工单小程序

## 本步目标

不脱离业务场景背语法，而是使用最少的 Python 知识完成工单创建、紧急程度判断、工单展示和数量统计。

## 程序的数据处理过程

```text
工单标题、描述和提交人
        ↓
create_ticket 函数创建工单字典
        ↓
classify_priority 函数检查紧急关键词
        ↓
display_ticket 函数显示工单
        ↓
循环统计紧急工单数量
```

## 本步使用的 Python 知识

- 变量：给数据起一个可重复使用的名称。
- 字符串：保存标题、描述和姓名等文字。
- 数字：保存工单编号和统计数量。
- 布尔值：保存“是或否”的状态。
- 列表：保存多张工单或多个关键词。
- 字典：使用有含义的字段保存一张工单。
- 条件判断：根据条件选择不同处理方式。
- 循环：依次处理多个数据。
- 函数：把一个明确功能封装起来重复使用。
- 返回值：把函数的处理结果交给调用位置。

## 为什么先使用关键词规则

关键词规则容易理解、容易测试，也能作为后续机器学习模型的比较基准。如果复杂模型没有明显超过简单规则，就需要重新考虑复杂模型是否值得使用。

## 当前规则的局限

- 只能识别提前写入列表的关键词。
- “并非无法登录”也可能被错误判断为紧急。
- 不理解上下文和近义表达。
- 关键词和业务规则需要人工维护。

这些局限正是后续引入数据分析和机器学习的原因。

## 面试题与参考答案

### 问题一：为什么先做规则基准，而不是直接使用复杂模型？

参考答案：规则方法实现快、可解释、容易测试，可以提供最低效果基准。后续只有当机器学习方法在准确率、维护成本或泛化能力方面明显更好时，增加复杂度才有价值。

### 问题二：列表和字典有什么区别？

参考答案：列表按位置保存一组数据，适合多张工单或多个关键词；字典按字段名称保存值，适合表示一张包含编号、标题、状态等不同属性的工单。

### 问题三：函数有什么作用？

参考答案：函数把一个明确功能封装起来，可以减少重复代码、提升可读性并方便单独测试。本程序把分类、创建和显示工单拆成不同函数，使每个函数只有一个主要职责。

### 问题四：当前关键词分类有什么缺点？

参考答案：它依赖人工维护关键词，不能理解上下文、否定表达和同义表达。后续可以收集带类别标签的历史工单，训练文本分类模型，并与规则基准进行量化比较。
